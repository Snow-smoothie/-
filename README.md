# オリジナリティバトルゲーム

自分だけのキャラクターを作り、友達とオンライン対戦するターン制バトルゲームです。キャラクターの能力やわざを自由に組み合わせて、自分らしいチームで勝利を目指しましょう。

## 遊び方

1. `index.html` をブラウザーで開きます。
2. 先に遊ぶ人が「部屋を作る」を押し、表示されたルームIDを相手に共有します。
3. 相手はルームIDを入力して「部屋に入る」を押します。
4. それぞれキャラクターを3体作成し、「準備完了！」を押すとバトルが始まります。
5. 自分のターンにわざを使うか、別のキャラクターに交代して戦います。相手チームのキャラクターをすべて倒すと勝利です。

## キャラクター作成ルール

- キャラクターは1チームにつき3体です。
- 1体ごとに、HPと攻撃予算の合計を1500ポイントにします（HP・攻撃予算はそれぞれ100〜1400）。
- 1体につき、わざを1〜6個設定できます。わざの威力の合計は、そのキャラクターの攻撃予算以内にしてください。
- 最初の3つのわざには、確率で発動する特殊効果を設定できます。追加ダメージ、回復、ダメージ軽減、状態異常から選べます。
- キャラクター画像はキャンバスに描くか、HTTPSの画像URLを指定できます。

## 動作環境と注意

- PeerJSをCDNから読み込むため、ゲームの起動とオンライン対戦にはインターネット接続が必要です。
- 接続環境やネットワーク設定によっては、相手と接続できない場合があります。
- オンライン対戦では、相手と同じルームIDを共有してください。
